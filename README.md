# Maquette MANTA – vente aux particuliers

Maquette de travail (non publique) du système de vente de MANTA aux particuliers :
page « particuliers » avec simulateur d'aides, assistant IA de démonstration et e-mails automatiques.

- `index.html` : sommaire
- `systeme.html` : qui fait quoi entre l'IA et Pierre
- `particuliers.html` : la page du site
- `assistant.html` : la conversation de démonstration
- `emails/` : les 5 e-mails envoyés automatiquement
- `simulation-site-v1/` : simulation du site complet manta-health.com dans ce style (29/10/2026)
- `simulation-site-v2/` : version 2 après les retours de Pierre et Élodie (télécommande animée, prêt gratuit, vidéos, équipe)

Les familles, numéros et dates sont fictifs. Site non indexé par les moteurs de recherche.
